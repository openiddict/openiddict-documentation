# 集成

OpenIddict 为 ASP.NET、ASP.NET Core、Entity Framework 6、Entity Framework Core 和 MongoDB 提供了官方支持的包。

由 OpenIddict 社区维护的开源集成文档可以在其各自的仓库中找到：
- **[OpenIddict.AmazonDynamoDB](https://github.com/ganhammar/OpenIddict.AmazonDynamoDB)** 由 [ganhammar](https://github.com/ganhammar) 开发：OpenIddict 的 Amazon DynamoDB 存储。
- **[P41.OpenIddict.CouchDB](https://github.com/panoukos41/couchdb-openiddict)** 由 [Panos Athanasiou](https://github.com/panoukos41) 开发：OpenIddict 的 CouchDB 存储。
- **[pixel-identity](https://github.com/Nfactor26/pixel-identity)** 由 [Nishant Singh](https://github.com/Nfactor26) 开发：使用 OpenIddict 和 ASP.NET Identity 的即用型 OpenID Connect 服务，提供基于 Blazor 的用户界面，用于管理用户、角色、应用程序和范围，支持多种数据库。

Rock Solid Knowledge 提供的商业支持组件：
- **[OpenIddict.AdminUI](https://www.openiddictcomponents.com/products/adminui?utm_source=openiddictgithubdocumentationadminui&utm_campaign=openiddict)** 由 [Rock Solid Knowledge](https://www.rocksolidknowledge.com/) 开发：排名第一的 OpenIddict 管理界面工具。提供网络门户和可编程 API 来管理您的 OpenIddict 配置和用户。
- **[OpenIddict.SAML2P](https://www.openiddictcomponents.com/products/saml2p?utm_source=openiddictgithubdocumentationsaml&utm_campaign=openiddict)** 由 [Rock Solid Knowledge](https://www.rocksolidknowledge.com/) 开发：使 OpenIddict 能够作为 SAML 身份提供者 (IDP) 或 SAML 服务提供者 (SP) 的理想选择。
